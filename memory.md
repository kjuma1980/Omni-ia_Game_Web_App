1. **Flujo de Git:** Nunca hacer merge a 'main' sin solicitud explícita del usuario. Trabajar siempre en la rama de feature actual.

9. **COMMITS OBLIGATORIOS:** SIEMPRE, de forma obligatoria y sin excepción, después de cualquier cambio autorizado, ajuste de código o resolución de bug exitoso, se debe realizar un commit en Git. Esto garantiza la trazabilidad y la integridad histórica de la rama del proyecto.

## Arquitectura Crítica

### Frontend (React)
- **Entry:** `index.tsx` → `App.tsx` (orquestador de tabs y estado global)
- **5 Tabs:** ASSETS, ANIMATION, NARRATIVE, SCRIPTS, AUDIO
- **Componentes:** `AssetGenerator.tsx`, `AnimationStudio.tsx`, `NarrativeGenerator.tsx`, `CodeAssistant.tsx`, `AudioDesigner.tsx`, `SettingsModal.tsx`
- **Estado:** Un único `ProjectData` object con auto-save a IndexedDB cada 1s

### Service Layer
- **`aiProvider.ts`** — Router Universal: decide entre cloud (Gemini) y local (ComfyUI/Ollama) según `apiSettings`
- **`geminiService.ts`** — Cloud: Gemini Flash Image, Veo 3.1, TTS Preview, Pro/Flash para texto
- **`localService.ts`** — Local: Ollama API, ComfyUI workflow injection, Suno/Udio stubs
- **`db.ts`** — IndexedDB wrapper (autosave con key 'autosave')
- **`utils/audioUtils.ts`** — Decodificación base64, AudioContext, efectos de voz, `applyVoiceEffects`, `VOICES_WITH_EFFECTS`

### Motor de Prompts (aiProvider.ts)
- Segmentación total por `ActionType` (Idle, Walk, Attack, Jump, Static Object, T-Pose, Model Sheet)
- Modo `background` tiene pesos negativos radicales (3.0) para eliminar humanoides
- Glosario ES→EN en `constants/glossary.ts`

### Backend Rust (src-tauri/src/lib.rs)
- **Comandos:** `check_service_status`, `launch_comfyui`, `stop_comfyui`, `launch_edge_tts`, `stop_edge_tts`, `proxy_request`, `save_image`, `save_project_file`
- **Proxy HTTP:** Timeout 600s, convierte imágenes a base64 automáticamente
- **Paths hardcoded:** ComfyUI en `G:\apps\all_comfyui_installer\ComfyUI`, Edge TTS en raíz del proyecto

### Servicios Externos
- **ComfyUI:** `http://127.0.0.1:8188` (ubicación real: `G:\apps\all_comfyui_installer\ComfyUI`)
- **Ollama:** `http://localhost:11434`

- ✅ `launch_edge_tts` y `stop_edge_tts` faltaban en `invoke_handler` (2026-05-03)

- ✅ **CRÍTICO — RESUELTO (2026-05-20):** `heroic_male` en español generaba audio con el texto del audio de referencia. Causa: El usuario reemplazó el archivo `heroic_male_es.wav` con su propio audio personalizado de 48s, pero el archivo de transcripción `heroic_male_es.wav.txt` seguía conteniendo la frase de plantilla de 10s. VibeVoice intentaba alinear y fallaba leyendo la transcripción. Solución: Renombrar `heroic_male_es.wav.txt` a `*.txt.bak` para forzar a VibeVoice a no usar transcripción conflictiva, permitiendo generación perfecta zero-shot.
- ✅ **Inyección de Duración Inteligente y Masiva (2026-05-22):** Resuelto el bug donde campos duplicados en el workflow (`duration` y `seconds`) no se sobrescribían. Ahora se recorre de forma masiva todos los nodos del JSON buscando variantes del campo de duración y se sobrescriben simultáneamente. Además, si el input is un enlace (`[nodeId, output]`), la app sigue el enlace y modifica el `inputs.value` del nodo primitivo origen.
- ✅ **Toggle de Activación y Estimador por BPM (2026-05-22):** Implementado Toggle en UI ("FORZAR DURACIÓN EN EL WORKFLOW") para activar/desactivar la inyección del tiempo estimado o ingresado. Calibrada la heurística del estimador de música utilizando la fórmula exacta `totalBeats = (words * 2.5) + 35` y `segundos = Math.round((totalBeats / BPM) * 60)` con límites entre 30s y 600s, alineándose con la herramienta del usuario.
