INSTALADOR EN 1 SOLO CLIC

Script del Agente GPU OmniDeploy

¿Para qué sirve este script y cuál es su fin?
Este instalador configura el Agente Proveedor de GPU OmniDeploy en tu ordenador. Permite que la Web App (https://fenixdev.cloud) se comunique de forma remota y 100% segura por HTTPS con tu servidor local de ComfyUI. Podrás iniciar o detener ComfyUI directamente desde tu navegador web y prestar la potencia de tu GPU a tu cuenta desde cualquier lugar.
✓
Cero Exposición de Secretos: No expone ninguna clave ni contraseña del servidor.
✓
Inicio con Windows: Se añade al inicio automático (shell:startup) en modo silencioso.
✓
Consumo Ultraliviano: Menos de 15 MB de memoria RAM y 0% CPU en reposo.
✓
Configuración Flexible: Te solicita la ruta de tu ComfyUI en la primera ejecución.
